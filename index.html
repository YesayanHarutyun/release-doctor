How it works

  1. Reads your package locally. We open the APK, AAB or AAR in your browser and read only the native library headers and the manifest.
  2. Checks what Google Play checks. 16 KB alignment of every 64-bit library, packaging of uncompressed libraries, and your target API level.
  3. Tells you what to change. Each failing library is matched to the plugin or SDK that ships it, with the version that fixes it and the command to run.

Questions

Why does Google Play say my app doesn't support 16 KB memory page sizes?

Newer Android devices can use 16 KB memory pages. Native libraries (.so files) built with the old 4 KB alignment can't load on them, so Google Play rejects app updates whose 64-bit libraries aren't 16 KB-aligned. The fix is almost always to upgrade the plugin or SDK that ships the library, or to rebuild your own native code with NDK r28 or newer.

Which apps are affected?

Only apps that ship native code. That includes most Flutter, React Native and Unity apps, and any app that uses libraries such as CameraX, ML Kit, SQLite, TensorFlow Lite or FFmpeg. Pure Kotlin or Java apps without .so files are not affected.

What is the target API 36 requirement?

Since 31 August 2026, new apps and app updates on Google Play must target Android 16 (API level 36). Apps that targeted older versions can stay on the store, but you can't publish updates until you raise the target.

Is my file uploaded anywhere?

No. The file is read with your browser's built-in APIs and never leaves your computer. Once the page has loaded, the scan even works offline.

Play Console still complains after I fixed everything.

Scan the exact build you uploaded. In Play Console, open App bundle explorer, pick the release and check "Memory page size"; it lists the libraries Google flagged. Packaging problems with uncompressed libraries also depend on your Android Gradle Plugin version (8.5.1 or newer handles them).

My library says "not in our database yet".

We add libraries as they show up in real reports. The fix steps shown for unknown libraries tell you how to find which dependency ships the file.
